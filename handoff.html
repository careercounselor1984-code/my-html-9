관리자 계정 확인 중

직원 계정과 관리 범위를 확인합니다.

상담일정표에서 로그인

1. 기존 담당자 확인

직원 계정관리에서 먼저 비활성화한 직원만 선택할 수 있습니다. 이 화면에서 계정을 활성화하거나 비활성화하지 않습니다.

인계 범위: 서버에 저장된 내담자 일정관리 자료(지정일·훈련·기간만료·참고 메모)와 직접 선택한 향후 상담예약. 개인 할 일·일반 업무 메모·지난 상담예약·계정·알림기기는 포함하지 않습니다. 통합본의 각 PC에만 저장된 상담일지·IAP 원문은 별도 파일로 인계해야 합니다.

2. 내담자별 새 담당자 지정

내담자 / 등록번호IAP 수립일 / 만료일새 담당자
기존 담당자를 선택하세요.

3. 함께 옮길 상담예약 선택 선택 사항

동명이인 혼동을 막기 위해 자동으로 연결하지 않습니다. 각 예약의 내담자를 확인하고 인계할 내담자를 직접 선택하세요. ‘옮기지 않음’인 예약은 기존 담당자에게 그대로 남습니다.

일시예약 이름 / 상담 구분연결할 인계 내담자
기존 담당자를 선택하세요.

4. 최종 확인 후 인계

실행 전에 원본과 인계 이력을 서버에 함께 보존하며, 처리 실패 시 전체 변경이 취소됩니다. 인계 이후 새 담당자가 자료를 수정하거나 관련 예약을 사용했다면 자동 취소할 수 없습니다.

인계 처리 이력

수정이 없는 인계만 전체 취소할 수 있습니다. 일부 내담자만 되돌리거나 수정 후 자료를 덮어쓰는 작업은 지원하지 않습니다.
