직원 연락망에 등록된 회사 이메일로만 일정표를 이용할 수 있어요.

직원 전용 계정으로 로그인해 주세요. 기존 PC에서 로그인 중이라면 로그인 후 비밀번호를 설정할 수 있습니다.

기존 이메일 링크 로그인 (메일 한도 제한)

이메일 링크로 이미 가입한 직원의 보조 로그인 수단입니다. 신규 계정은 만들지 않으며, 발송 제한으로 실패할 수 있습니다.

비밀번호는 Supabase 인증 서버에서 검증되며 일정 데이터나 GitHub 소스에 저장되지 않습니다. 신규 직원 계정은 관리자가 생성합니다.

내 비밀번호 설정·변경

현재 로그인한 본인 계정의 비밀번호를 설정합니다. 8자 이상의 고유한 비밀번호를 사용하고 다른 사람과 공유하지 마세요.

상담은 선택한 시간에 30분으로 자동 등록돼. 연차는 '연차 칸 선택'을 켠 후 칸을 클릭하거나 마우스로 드래그해 한 번에 지정할 수 있어. 금요일은 12:00까지만 근무하고 공휴일·대체공휴일·센터 휴무일은 등록할 수 없어.

선택한 내 일정에만 등록돼요. 다른 직원의 연차·교육은 각자의 나의 일정에서 입력해 주세요.

하루 전체 일정으로 처리할 항목을 선택하세요.

센터 직원 일정 요약

직원별로 연차·교육·출장 등만 합산하여 표시해요.

조회 전용 화면이에요. 직원 개별 일정 등록·수정은 나의 일정에서, 센터 문을 닫는 공동 휴무 등록은 ＋ 센터 자체 휴무 등록에서 해주세요.

공통 비고 · 회사 행사

회식·워크숍·행사 등은 상담시간을 막지 않고 일정표에 안내로 표시해요.

등록된 행사·비고

공동 휴무일 등록

공휴일 외에 센터 운영이 중단되는 날만 등록해 주세요. 개인 연차·외부교육·출장은 여기서 등록하지 않습니다. 전체 센터 또는 해당 센터에 적용할 수 있어요.

센터별 직원 목록

직원 연락망을 기본 목록으로 등록했어. 새 직원 추가 또는 목록에서 제외할 수 있어. 일정이 등록된 직원은 목록 제외 후에도 기존 일정이 남아 있어.

기억된 참여자 관리

자동완성 명단에서만 삭제해. 이미 등록된 상담 일정은 그대로 유지돼. 구분표시에는 생년월일이나 연락처를 쓰지 않는 것을 권장해.
