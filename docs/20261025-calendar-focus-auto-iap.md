# 노트북 상담표와 IAP 자동 보완

## 화면 너비

기본 화면은 왼쪽 메뉴와 오른쪽 선택일 목록을 접고 상담표가 가용 너비를 사용한다. 메뉴와 날짜 탐색은 상단 ‘메뉴’, 선택일 목록은 ‘일정 목록’으로 연다. 넓은 화면에서는 메뉴 고정을 선택할 수 있다. 창 너비는 외부 모니터가 아니라 현재 일정표가 표시되는 iframe/브라우저의 실제 너비를 기준으로 한다.

## 연속 근무 블록

같은 날짜·직원·종류·내용의 연속된 근무 일정을 한 블록으로 표시한다. 연차 네 칸은 예를 들어 ‘연차 16:00–18:00’으로 보이며, 외부홍보·외근·교육 등도 같은 기준을 적용한다. 다른 종류·메모·직원·날짜, 빈 시간 또는 중복 일정이 끼어 있으면 별도로 표시한다.

원본 기록의 ID와 저장 내용은 변경하지 않는다. 복수 기록으로 된 블록을 누르면 각 원래 등록을 확인·수정할 수 있다. 기존 칸 선택·드래그 기능의 실제 셀은 유지하고, 인쇄 원본과 이름 마스킹도 유지한다. 모바일의 기존 일간 목록은 그대로 사용한다.

## 입력을 줄이는 자동 보완

수급자 목록을 한 번 가져와 이름과 IAP 등록번호를 연결한 뒤, 같은 브라우저의 공식 IAP 저장소 변경을 감지해 이미 본인이 관리하는 내담자의 빈 수립일·만료일과 없는 훈련을 자동 보완한다. 일정표가 열려 있으면 인증된 본인 전용 내담자 페이지를 숨겨진 iframe으로 재사용하므로 내담자 관리 화면을 매번 열 필요가 없다.

- 자동 보완은 기본 켬이며 내담자 관리의 ‘IAP 자동 보완’으로 계정별 해제할 수 있다.
- 조회·저장은 기존 본인 인증/RLS와 소유자·종류·수정시각 조건을 사용한다. 로그아웃하면 숨겨진 페이지를 제거하고 진행 응답으로 이름을 다시 표시하지 않는다.
- 직접 수정한 날짜, 같은 이름의 다른 훈련 일정, 다른 IAP 수립일·유형, 다른 기기 변경 또는 저장 용량 충돌은 자동으로 덮지 않는다. 확인이 필요한 자료로 남긴다.
- 취업·중지·종료 상태에는 자동 보완하지 않는다.
- 새 내담자를 이름 없이 생성하거나, 이름만으로 매칭하지 않는다. 초기 수급자 명단 연결이 필요하다.
- 전산도우미의 정보도 IAP 공식 저장소에 저장된 경우 이 흐름에 포함된다. 확장 프로그램 내부 저장소나 고용24 전산을 새로 직접 수집하지 않는다. 원본 IAP와 실제 상담 예약은 변경하지 않는다.

## 검증

노트북 1366/1536, 넓은 화면 1920, 1280/768/390px에서 다섯 보기를 확인한다. 합성 자료로 연차 네 기록의 단일 표시·원본 보존·수정 목록·메뉴/상세 열기와 닫기·퇴장 시 정보 제거를 검증한다. 실제 숨겨진 내담자 페이지까지 연결한 브라우저 fixture에서 IAP의 새 훈련과 빈 만료일이 별도 입력 없이 반영되고 수기 지정일은 유지되는지 확인한다.

자동 보완 켬/끔, 재반영 중복 방지, 소유자/수정시각 조건, 로그아웃/늦은 타이머 취소 및 기존 저장·인쇄·모바일 회귀 검사를 포함한다. 실제 직원 계정과 내담자 기록은 테스트에 사용하지 않는다.
