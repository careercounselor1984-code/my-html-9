# 센터 게시판 · 2026-10-28

소속 센터 직원이 공유 메모·공지·인원 취합 카드를 작성한다. 각 직원은 본인 답변을 저장·수정하며 인원 0과 미제출을 구분한다. 완료 카드는 보관되고 제목·본문·답변으로 검색할 수 있다. 작성자와 같은 센터 관리자가 카드를 수정·완료 처리한다.

통합본·일정표·내 할 일·내담자 일정관리·인계 화면의 공통 안내에서 중요 공지와 본인의 미제출 요청을 연다. 공지 확인 또는 인원 제출 시 해당 안내를 숨긴다. 중요 공지 내용이 변경되면 다시 확인 대상이 된다. 노출 종료 일시와 완료 상태는 메뉴 안내에서만 제외하며 보관 카드를 삭제하지 않는다.

중요·긴급 카드를 저장하면 기존 `schedule_push_subscriptions`에 알림을 허용한 같은 센터 동료에게 PC/기기 푸시를 보낸다. 일반 카드와 답변 저장에는 푸시를 보내지 않는다. 같은 카드 수정본은 기기별로 중복 발송하지 않는다. 서버가 전송을 수락한 수와 실제 Windows 표시 여부는 다르다. Windows 알림 권한과 브라우저 백그라운드 실행 상태를 사용 PC에서 확인해야 한다. 마감 일시는 화면에 표시하며 자동 마감 독촉은 이 버전에 포함하지 않는다.

## 저장·인증

신규 테이블 3개와 `center-board` Edge Function을 추가했다. 기존 일정·상담 데이터는 변경하지 않는다. `schema.sql`이 적용 SQL이며 서버 함수의 JWT 검증을 유지한다. 브라우저 역할의 테이블 권한은 모두 회수하고 RLS도 켰다. 함수가 사용자 토큰을 검증한 뒤 활성 직원의 센터·작성자 권한을 매 요청 확인한다. 센터·작성자·답변 작성자는 사용자 입력을 신뢰하지 않는다. 답변은 카드/직원 복합키로 따로 저장하며 카드 수정은 revision 비교로 충돌을 감지한다. 게시판 내용은 PC 저장소에 보관하지 않는다.

통합본은 기존 바로가기·설치를 유지한다. 새 `센터 게시판` 메뉴와 기존 전사 공용 게시판은 함께 사용할 수 있다. iframe 연결은 정확한 origin/source를 확인하며 직원 이름이 다르면 연결을 거절한다. 로그아웃 시 iframe과 내용이 제거된다. 잠금화면 푸시는 카드 제목·내용 대신 범용 문구만 표시하며 클릭 후 로그인·센터 권한을 다시 확인한다.

## 검증

- `node tests/center-board.test.cjs`: 센터/작성자 격리, 동시 답변, 0명, 수정 충돌, 보관, 답변 검색, 읽음·노출 종료, 푸시 대상·중복 방지.
- `node tests/center-board-push.test.cjs`: 알림 개인정보 제외, 열린 앱/닫힌 앱의 카드 연결, 기존 알림 유지. 통합본에도 동일 검사가 있다.
- `node tests/center-board-browser.cjs`: 이 PC의 Playwright/격리 Chrome으로 합성자료 검사. PC/390px, 취합, 카드 저장, 검색, HTML 문자 처리, 계정·센터 전환, 통합본 iframe 인증과 로그아웃. 실제 알림 발송 없음.
- 기존 인증·메시징·미니 일정표·알림 회귀 검사 및 양쪽 전체 화면 시작 검사 통과.
- 운영 DB 트랜잭션 안에서 임시 카드/답변/합계/수정 충돌을 검사 후 롤백. 카드 0건, 신규 테이블 RLS 3개, anon/authenticated/PUBLIC 테이블 권한 0건 확인.
- Supabase 보안 검사의 기존 항목은 유지되며 신규 게시판 객체의 경고는 없다.

배포 순서는 저장소 SQL → `center-board` 함수 → 일정표 화면 → 통합본 화면이다. 웹 화면 롤백은 해당 프런트엔드 커밋을 되돌리며, 사용자가 작성한 신규 테이블은 유지한다.
