# 자동로그인 복원 (2026-10-19)

사용자 요청으로 업무용 PC의 자동로그인을 다시 유지한다.

- 통합본은 인증 세션을 로컬 영속 저장소에 보관하고 기존 세션 전용 토큰은 읽을 때 검증된 저장 후 이전한다. 저장소 사용이 제한되면 예외로 앱을 중단시키지 않는다.
- 일정표·내담자 관리·내 할 일은 로그인 유지가 기본이다. 사용자가 명시적으로 해제한 설정(0)은 그대로 존중한다. 로그인 유지가 켜져 있으면 세션 전용 토큰을 영속 저장소로 이전한다.
- 로그아웃은 인증 토큰을 두 저장소 모두에서 제거한다.
- 개인정보 임시 초안의 세션/24시간 정책과 암호화 백업은 변경하지 않는다.
- 계정 활성·퇴사·비밀번호 변경·등록기기·기존 만료기간 검사는 유지한다. 자동로그인이 서버 권한 확인을 건너뛰지 않는다. 두 시스템의 퇴사 처리는 여전히 각각 필요하다.
- 유효한 로그인 정보가 없거나 기존 서버 만료기간이 지난 경우 한 번 다시 로그인해야 한다. 비밀번호를 별도로 저장하지 않는다.
