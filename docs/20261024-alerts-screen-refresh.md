# 2026-10-24 상담 프로그램·추천서·알림 개선

사용자 제공 「국민취업지원제도 업무매뉴얼(2026.1)」 인쇄쪽 196–201을 기준으로 활동 메뉴와 선택별 안내를 보완했다. 단기집단상담, 2일 이상 집단상담, 심리·진로·취업상담, 클리닉, 재진단 필수 대면상담, 복지·금융 집단프로그램, 전문성 향상 및 사회봉사 항목을 제공한다.

상담·프로그램 계획 개수를 기존 회차 합계에 반영한다. 집단상담은 수료일(행 종료일) 기준이며, 기존의 구분 없는 집단상담은 단기/2일 이상 구분을 확인해야 한다. 자비·미인정 과정은 전체 10일·40시간, 출결관리, IAP·취업 필요성 확인 및 해당 지급주기 예정일수 선택을 모두 확인해야 계획 개수에 반영된다. 확인 사실은 저장·복원되며 과정명 변경 시 재확인이 필요하다. 훈련 분할 시 해당 주기 예정일수 선택은 다시 확인한다.

출석률, 경조사, 중도 편입·폐강·취업에 따른 포기, 여러 과정 합산 예외는 화면에서 확인할 수 있다. 실제 출석·수료·증빙 없이 지급을 확정하거나 자동 승인하지 않는다. 특강 전체 2회 제한은 현재 표 밖의 과거 참여 이력도 별도 확인해야 한다. 사회봉사·창업 준비 등 개별 판단 항목은 무조건 1개로 자동 합산하지 않는다.

추천서는 입력·선택한 사실만 출력하며 빈 강점에 성실성·실무역량을 임의로 추가하지 않는다. 문장을 직접 편집하고 중복 강점 추가를 방지한다. 저장 프로필·기관·백업·메일 복사·공문 출력 흐름을 유지한다. 초기화 버튼은 상단 제목 영역에 배치한다. Gmail 초안은 로그인 직원 계정 또는 브라우저의 현재 계정을 사용한다.

청년일자리도약장려금의 과거 ‘2년 1,200만원’ 문구를 2026년 기업지원 및 별도 청년 인센티브 안내로 교체했다. 대상·중복지원 여부는 단정하지 않는다. 근거: [고용24 청년일자리도약장려금](https://www.work24.go.kr/cm/c/f/1100/selecSystInfo.do?systId=SI00000318), [고용촉진장려금](https://www.work24.go.kr/cm/c/f/1100/selecSystInfo.do?systId=SI00000370), [국민내일배움카드 운영규정](https://www.law.go.kr/행정규칙/국민내일배움카드운영규정).

통합본과 일정표의 팝업은 새 도착, 대신 상담·인계 요청, 중요 표시 공지, 출입 신청 확인만 대상으로 한다. 일반 연차 변경·종합보고·모집글은 알림함에 남긴다. 직원 이름별로 같은 브라우저의 표시 이력(최대 90일·2,000개)과 30분 미루기를 공유한다. 팝업 표시만으로 읽음 처리하지 않는다. 출입 신청 미완료의 오전 9시 기준 하루 1회 안내는 유지한다. 브라우저 저장소 삭제·다른 기기에서는 별도 이력이 적용된다.

검증: 기존 자동 회귀검사, 활동·추천서 DOM 검사, 팝업 순수 정책 검사, 1440/390px 실제 Chrome 화면, 출력·로그아웃·훈련 분할 검사. 서버 자료 변경과 실제 메일 발송 없이 합성 자료로 확인했다.
