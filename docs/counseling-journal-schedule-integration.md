# 좋은일자리 상담 일정관리 ↔ 상담일지 통합본 연계 요구사항

작성: 2026-10-09 / 사용자 요청을 추후 구현 시 누락하지 않기 위해 저장한 개발 메모.

## 향후 구현 (현재 미연동)

### 1. 상담일지 작성 후 다음 상담 예약
- 상담일지 통합본에서 초기상담 등 상담일지 작성 완료 시 **선택 항목**으로 "다음 상담 예약"을 제공한다.
- 다음 상담일(날짜, 시간), 내담자 이름을 입력하며, **이름은 현재 상담일지의 내담자명을 기본으로 자동 채운다**. 상담 유형은 사용자가 선택할 수 있다.
- 이용자가 선택 항목을 비워두면 일정을 만들지 않는다.
- 입력 시 저장/등록을 확인한 후 동일 직원의 상담 일정관리(Supabase) 주간/일일 표에 자동 추가한다. 30분 기본 단위, 기존 근무시간 규칙, 공휴일 제한, 중복예약 검사, 동명이인 처리 등을 그대로 유지한다.
- 같은 상담일지를 반복 저장했을 때 일정이 중복되지 않게 **상담일지 원본 ID + 다음상담 예약 키** 등으로 멱등성 확보한다. 다음 상담 변경/삭제 시 연결된 예약을 안전하게 갱신할 정책을 정한다.
- 내담자 정보를 URL, 브라우저 로그, 타 직원 화면에 노출하지 말고 기존 직원 이메일 인증/RLS/서버 권한을 사용한다.

### 2. 초간단 일정 입력 (v20 부분 구현)
- 별도의 상담구분 드롭다운을 안 건드리고 `홍길동 초기`, `김철수 IAP`, `박민수 해석`처럼 한 줄 입력한다.
- 마지막 단어가 알려진 상담구분일 때 자동 분리하여 내담자명/상담유형에 대입한다.
- v20 일정관리 웹 화면에 '빠른 상담 등록' UI를 구현. 날짜/시간을 화면에 표시해 확인 후 기존 저장 로직으로 등록한다. 상담일지 통합본에도 동일 입력 경험을 확장할 수 있다.
- 지원 구분: 초기, 해석, IAP, 컨설팅, 재진단, 훈련등록, 카드발급, 신청, 일경험, 연계 (사용 빈도에 따라 확장).

## 연계 전 필요한 서버 작업
- 상담일지 통합본과 일정관리의 로그인 계정/센터/담당 상담사를 동일 신원으로 매핑한다.
- 직접 클라이언트에서 테이블 접근을 늘리지 않고 기존 데이터 접근 정책을 재사용하거나 별도 검증된 예약 API를 만든다.
- 본인 일정과 동료 대신 예약은 서버에서 권한을 분리한다.
- 사용자 테스트: 빈 다음예약 필드, 정상등록, 이미 차 있는 시간, 중복저장, 동명이인, 날짜변경, 취소/연장, 모바일/PC 동기화.

**현재 상태:** 일정관리 v20의 한 줄 빠른 등록만 구현되어 있으며, 상담일지 통합본과 예약 자동 연동은 아직 개발하지 않았다.
