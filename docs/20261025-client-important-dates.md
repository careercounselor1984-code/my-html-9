# 내담자 일정관리: 등록한 모든 중요 날짜를 확인하는 화면

사용 목적은 수급자 목록, IAP 상담, 전산도우미 등에서 얻은 중요한 날짜를 남겨 놓고 챙기는 것이다. 날짜 종류에 따라 임의로 중요도를 매기지 않는다.

## 화면과 확인 기록

- 기본 화면은 오늘부터 7일 이내의 미확인 날짜를 보여 준다. 오늘, 지난 날짜·미확인, 기간별 조회, 확인 완료 및 정보 보완으로 이동할 수 있다.
- 지난 날짜는 조회 월과 상관없이 찾을 수 있다. 실제 미이행 여부를 자동 판단하지 않는다.
- 날짜별 확인 완료를 개인 서버 자료에 저장한다. 다시 해제할 수 있으며 날짜·내용이 바뀌면 재확인 대상으로 돌아온다.
- 지정일, 훈련 시작·종료, 서비스 만료, 재진단 외에 내용·날짜·출처를 가진 추가 중요일을 등록한다.
- 검색은 모든 보기에서 노출하고 전체 내담자 목록에는 다음 날짜와 지난 미확인 건수를 표시한다.

## 정보를 모으는 경로

1. **수급자 목록**: 기존 Excel 파일·복사 붙여넣기 미리보기와 본인 담당자 확인을 유지한다. 새 지정일이 표준 주기로 계산된 경우 계산일임을 표시한다.
2. **IAP 일정 보완**: 같은 브라우저의 공식 저장소 `iap_participant_records_v1`에 저장된 IAP 중 본인 목록과 등록번호가 일치하는 자료만 비교한다. 빈 수립일·만료일과 기존에 없는 훈련을 제안하고, 미리보기에서 선택한 내담자만 반영한다. 유형·IAP 수립일이 다르면 반영을 막는다. 기존 날짜와 동일 이름의 훈련이 다르면 기존 자료를 유지하고 안내한다. IAP의 활동 기간을 실제 활동 예약일로 추정하지 않는다.
3. **전산도우미·기타 자료**: 내담자 상세의 추가 중요일에 날짜를 기록하고 출처를 선택한다. 확장 프로그램 내부 저장소나 고용24 전산을 이 화면에서 직접 읽는 기능은 추가하지 않았다. 도우미 정보를 IAP에 저장한 경우에는 위 경로를 이용할 수 있다.

IAP 보완 건수를 버튼에 표시하고 다른 탭에서 공식 IAP 저장소가 바뀌면 비교 표시를 갱신한다. 자동 덮어쓰기는 하지 않는다. 원본 IAP나 실제 상담 예약도 수정하지 않는다.

## 저장과 검증

기존 `schedule_private_items`의 `kind='iap'` 자료에 추가 날짜·출처·날짜별 확인 정보를 보관한다. 사용자·종류·기존 수정시각을 조건으로 저장하며 충돌 시 기존 자료를 유지한다. 확인 저장 중 로그아웃하면 응답으로 화면을 다시 채우지 않는다.

운영 DB의 소유자별 SELECT/INSERT/UPDATE/DELETE 정책과 JSON 객체·20KB 미만 제약을 읽기 전용으로 확인했다. 스키마와 정책은 변경하지 않았다. 실제 내담자 자료를 읽거나 수정하지 않고 합성 자료로 검증했다.

검증 범위: 기존 수급자 가져오기·상태 정리·인계·개인정보 회귀 검사, 추가 날짜와 출처 저장, 날짜별 확인·취소와 동시 수정 충돌, IAP 미리보기/명시적 반영/재반영 중복 방지, 1440/1024/768/390px의 목록·월간·주간·일간 화면, 로그아웃 및 저장 응답 지연 시 정보 제거.
