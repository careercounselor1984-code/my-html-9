# 설치 없는 브라우저 미니 상담 일정표

## 사용할 주소
운영 반영 후: https://careercounselor1984-code.github.io/my-html-9/index.html?mini=1

기존 상담 일정관리에서도 '▣ 미니 일정표' 버튼으로 별도 작은 크롬 창을 열 수 있습니다. 별도의 Windows 프로그램이나 앱 설치는 필요 없습니다. 기존 직원 로그인과 서버 저장을 그대로 사용합니다.

## 매일 업무 중 사용하기
1. Chrome에서 상담 일정관리를 열고 '▣ 미니 일정표'를 클릭합니다. 또는 위 주소를 즐겨찾기에 저장합니다(Ctrl+D).
2. 미니창에서는 '내 일정 / 우리 센터 전체'를 선택할 수 있습니다. 본인 일정은 해당 날짜 전체, 센터 일정은 기본적으로 현재 시간 주변만 보여 줍니다. ‹, ›, 오늘 버튼으로 이동합니다.
3. 항목을 클릭하면 기존 등록·수정창으로 이동하고, '＋ 빠른 상담등록'으로 내담자 이름+상담구분과 빈 30분 시간을 입력합니다.
4. 기존 일정을 저장한 후 상태란의 '서버 저장 완료'를 확인합니다.
5. '전체 ↗' 버튼을 누르면 일반 일정표가 새로운 창/탭으로 열립니다.

## 우리 센터 일정 보기
- '우리 센터 전체'를 누르면 현재 시각 기준 **1시간 전 ~ 2시간 후** 범위의 상담·근무 일정만 먼저 표시합니다.
- '하루 전체'를 누르면 오늘 하루 모든 시간대의 센터 일정을 보여 줍니다. 과거나 미래 날짜를 선택하면 하루 전체 일정으로 표시합니다.
- 다른 상담사 일정은 조회 전용입니다. 상담 변경은 담당 상담사가 원래 일정표에서 처리해야 합니다.

## 크롬에서 항상 위에 표시하기 (선택)
- 최신 Windows용 Chrome 등 Document Picture-in-Picture API 지원 브라우저에서만 '항상 위에' 버튼이 보입니다.
- **항상 위에**를 누르면 작은 창이 다른 프로그램 위에 떠 있습니다. 해당 창에서도 일정을 살펴보고 빠른 상담을 등록할 수 있습니다.
- 항목을 눌러 상세 내용을 수정하거나 근무 일정 등록을 시작하면 고정 창을 닫고 원래 미니창의 편집 화면을 엽니다.
- '고정 해제' 또는 크롬의 닫기 버튼으로 원래 미니창 화면으로 돌아옵니다.
- **원래 미니창을 닫으면 항상 위 창도 종료됩니다.** 인터넷 연결, 크롬 권한, 회사 PC 정책에 따라 기능이 제한될 수 있습니다.
- 지원되지 않는 브라우저에서도 일반 작은 창으로 일정 조회·수정은 가능합니다.

## PC에서 자주 열기
- 브라우저에서 미니창 주소를 Ctrl+D로 즐겨찾기 해두고, Chrome 북마크바 또는 Windows 작업표시줄에 Chrome을 고정해 빠르게 여세요.
- Chrome '시작 그룹'에서 해당 주소를 시작 페이지로 추가하면 Chrome 실행 시 자동으로 열 수 있습니다. 단, 보안상 로그인 유지 설정을 확인하세요.
- 웹 보안상 사이트 자체는 컴퓨터 부팅 때 자동으로 실행하거나, 사용자의 동의 없이 항상 위 창을 시작할 수 없습니다.

## 개인정보·동기화
- '내 일정'에서는 본인 일정만 표시합니다. '우리 센터 전체'에서는 같은 센터 직원들의 일정만 읽기 전용으로 표시하며 다른 상담사의 내담자 이름·상담 메모·편집 ID는 미니창으로 넘기지 않습니다.
- 로그인되지 않으면 미니창에 일정 내용이 나타나지 않습니다.
- 기존 서버 데이터를 약 30초마다 확인하고, 사용 창이 다시 활성화됐을 때 재확인합니다. 브라우저 절전·네트워크 상태에 따라 지연될 수 있으며 서버 변경을 즉시 수신하는 방식은 아닙니다.
- 서버에 미전송 일정이 있으면 새로고침으로 덮어쓰지 않도록 보호합니다.
- 항상 위 창은 주변에 보일 수 있습니다. 공용 PC에서는 로그인 상태 유지를 해제하고 상담 정보가 보이지 않게 창을 닫아주세요.

## 검수 상태
- 자동 검사: 자바스크립트 구문, 직원별 일정 조회 범위, 빈 시간 산정, 미전송 보호, PiP 관련 브라우저 연결 로직.
- 사용자 환경에서 추가 확인 필요: 회사 계정 로그인, 동명이인, 실제 예약 저장·수정, 브라우저 PiP 동작, 서버 연결 지연.
