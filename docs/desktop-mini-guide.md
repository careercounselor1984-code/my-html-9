# PC 미니 상담 일정표 — 사용자 안내

## 실행
운영 배포 후 주소: https://careercounselor1984-code.github.io/my-html-9/index.html?mini=1
기존 전체 일정표의 PC 미니 일정표 버튼을 누르면 약 410×690 크기의 작은 창이 열립니다.
직원 이메일과 기존 비밀번호로 로그인합니다. 별도 계정이나 별도 일정 저장소를 만들지 않습니다.
미니창은 로그인한 직원 본인의 예약과 개인 근무 일정만 표시합니다.
예약을 누르면 기존 수정 화면이 열립니다. 빠른 상담등록에서 예시 '홍길동 초기'처럼 이름과 구분을 적고 날짜·빈 30분 시간대를 선택하면 기존 검증 절차로 등록합니다.
근무 일정 버튼은 기존 근무·교육·외근 등록 화면을 엽니다. 전체 보기는 원래 전체 일정표를 별도 창에서 엽니다.

## PC에 앱으로 설치
1. 위 주소로 접속해 Chrome 또는 Edge의 '앱 설치' 혹은 '이 사이트를 앱으로 설치'를 선택합니다.
2. 설치한 앱을 Windows 작업표시줄에 고정합니다.
3. 브라우저 정책이나 설치 환경에 따라 메뉴 이름이 다를 수 있습니다.

## 항상 위에 표시 / PC 켤 때 실행
웹페이지 자체는 Windows 항상 위 또는 시작 프로그램 등록 권한이 없습니다.
필요하면 사용자가 Microsoft PowerToys의 Always On Top 기능을 별도로 설정할 수 있습니다(기본 단축키 Win+Ctrl+T).
부팅 후 자동 실행도 운영체제 또는 회사 PC 정책에 맞게 사용자가 직접 설정해야 합니다.

## 동기화·안전
현재 일정표의 약 30초 주기 서버 재조회와 창 활성화 시 재조회 기능을 그대로 사용합니다. 변경 즉시 서버 이벤트를 수신하는 방식은 아닙니다.
기존 서버 저장과 충돌 방지 절차를 재사용합니다. 중요한 등록 후 '서버 저장 완료' 문구를 확인하세요.
미전송 기록이 있으면 강제 재조회하지 않습니다. 로그아웃 상태에서는 내담자 일정 내용이 표시되지 않습니다.
공용 PC에서는 로그인 상태 유지를 해제하고, 주변에서 화면을 볼 수 있는 경우 미니창을 최소화하세요.

실사용 환경에서 추가 검수 필요: 직원 로그인, 상담 예약 등록·수정, 동명이인, 장시간 동기화, PC별 앱 설치.
