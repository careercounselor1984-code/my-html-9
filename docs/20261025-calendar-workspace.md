# 일정표 화면 구성 개선 — 2026-10-25

앞선 색상·간격 조정만으로는 상담표가 화면 아래로 밀리고 주요 기능이 분산되는 문제가 남았다. 이번 변경은 화면 탐색과 작업 배치를 다시 구성한다.

## 실제 제품 화면에서 참고한 원칙

- [Google Calendar](https://workspace.google.com/intl/ko/products/calendar/): 날짜 탐색과 보기 전환을 달력 가까이에 배치하고 오늘·선택일을 구분한다.
- [Notion Calendar](https://www.notion.com/product/calendar): 왼쪽 탐색, 가운데 일정표, 선택일의 상세 내용을 분리한다. 화면이 좁으면 상세 목록은 버튼으로 연다.
- [flex 근태관리](https://flex.team/landing/service/time-tracking): 직원별 일정에서 이름과 근무·휴가 종류를 구분하고 색상에만 의존하지 않는다.

공식 공개 제품 페이지에 나온 화면을 확인해 배치 원칙을 참고했다. 이미지·상표·제품 UI 코드를 복제하지 않았다.

## 배치와 동작

- 왼쪽: 상담일정표 / 내 할 일 / 내담자 일정관리 / 연차 일정표, 미니 달력, 일정 구분, 표 간격 설정, 미니 일정표 실행.
- 위쪽: 계정과 알림·공유·관리 도구. 상담표 바로 위에는 일간·주간·월간·연차·센터 보기와 기간 탐색, 예약·등록·인쇄·보고용 이미지 기능.
- 가운데: 기존 상담 시간표와 월간표. 주간 날짜 제목이나 미니 달력을 누르면 선택 날짜가 바뀐다.
- 오른쪽: 1480px 이상에서 선택일 일정·직원별 연차를 보여 준다. 그보다 좁은 화면은 ‘일정 목록’ 버튼으로 연다.
- 연차표: 직원 이름, 종류, 등록 시간·출근 시간을 분리해 표시한다. 비어 있는 날짜의 반복 안내를 줄인다.
- 휴가 시간은 현재 조회 월에 등록된 일정 합계이며 잔여 연차·승인 여부·실제 출근을 판정하지 않는다.
- 모바일: 메뉴는 접이식이고 날짜 스와이프 및 하단 빠른 예약·근무 등록을 유지한다.
- 표 간격만 기기에 저장한다. 상담 데이터의 저장 방식과 서버 권한은 변경하지 않는다.

## 검증

합성 데이터로 Chrome 1600 / 1440 / 1280 / 768 / 390px에서 다섯 보기를 확인했다. 날짜 이동, 상세 목록 열기·닫기, 메뉴 열기·닫기, 빠른 예약, 간격 설정, 직원별 범위와 로그아웃 시 새 화면의 정보 제거를 확인한다. 기존 인쇄 마스킹·금요일 근무·내담자 관리·알림 회귀 검증도 수행한다.

새 Chrome 회귀 검사 `tests/calendar-workspace-browser-smoke.cjs`는 CI에 포함된다. 운영 화면의 실제 직원 계정으로 로그인하거나 실제 상담 데이터를 변경하지 않고 검증한다.
