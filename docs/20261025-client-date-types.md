# 중요 날짜 종류와 별표 표시

내담자 일정관리의 서비스 기간만료일과 구직인증번호 만료일을 분리했다. 일정 종류는 기존 지정일·훈련 시작/종료·재진단에 구직인증번호 만료, 출근 예정, 출석통보 지정일, 기타 중요일을 포함한다.

- 구직인증번호 만료일은 내담자 상세의 별도 날짜 입력이다. 수급자 목록에 대응 제목행이 있으면 가져오며, 공란이나 다른 실제 날짜로 기존 값을 덮지 않는다.
- 출근 예정·출석통보 지정일은 ‘추가 중요일’에서 종류·날짜·내용·출처·준비사항을 기록한다. 출근 예정만 등록했다고 취업 상태로 변경하지 않는다. 실제 취업·종료 처리는 기존 명시적 상태 변경을 사용한다.
- 각 날짜의 ‘★ 표시’와 ‘확인 완료’는 별개다. 별표는 개인적으로 눈에 띄게 표시하는 용도이며, ‘★ 모아보기’는 전체 기간의 표시한 날짜를 보여 준다. 완료한 일정은 기존 완료 포함 설정을 따른다.
- 기존 추가 중요일의 `custom:<id>` 키와 완료·제외 기록은 유지한다. 종류·내용·날짜·준비사항이 바뀌면 다시 확인할 수 있도록 완료 상태를 해제한다.

## 전산도우미 만료일 연결

통합본의 기존 기본정보 전달 메시지에 있는 `jobCertExpire`를 사용한다. 활성 직원 로그인, 같은 창·origin, 신선한 전달 시각과 유효한 날짜를 확인한 뒤 계정 이메일별 임시 저장소에 IAP 등록번호·만료일·출처 시각만 저장한다. 이름·주민정보·연락처·실제 구직인증번호는 추가 저장하지 않는다. 로그아웃 시 임시 자료를 지운다.

일정표는 본인 로그인 이메일과 본인 목록의 IAP 등록번호가 일치하는 임시 자료만 읽어 빈 구직인증 만료일을 자동 보완한다. IAP 공식 저장 자료가 아직 없어도 기존 내담자의 등록번호가 확인되면 가능하다. 다른 날짜가 이미 있으면 확인 대상으로 유지한다. 원본 전산·확장 프로그램의 저장 형식·서버 정책은 변경하지 않는다.

## 참고 매뉴얼

사용자가 제공한 `★국민취업지원제도업무매뉴얼(2026.1).pdf`의 구직신청 관련 처리 내용을 확인했다. PDF 118페이지(인쇄 110쪽)는 서비스 종료와 구직인증번호 마감 처리를 별도로 다룬다. 해당 날짜를 같은 값으로 취급하거나 서비스 기간으로 구직인증 만료일을 추정하지 않는다.

출석통보 지정일은 확인한 실제 통보 날짜를 기록하며 자동 계산 규칙이나 미출석에 따른 법적 판단을 추가하지 않았다. 훈련 출결·수당 인정 기준도 변경하지 않는다.

## 검증

새 종류와 기존 키 유지, 구직인증/서비스 날짜의 분리, 별표·메모의 저장·해제, 전체 기간 모아보기, 엑셀 날짜 인식과 수기값 보존, 계정·등록번호·시간 검증과 로그아웃 제거를 확인한다. 합성 자료로 PC·모바일 및 기존 저장·상태·인계·자동 보완 회귀 검사를 수행한다.
